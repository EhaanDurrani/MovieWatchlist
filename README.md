# Movie Watchlist Manager (SCD Lab Project)

A Java Swing desktop app for managing a personal movie watchlist — add, rate, filter, and track watched/unwatched movies.

## Tech Stack

- Java (Swing GUI)
- JUnit 5 for testing
- 3-layer architecture: model / service / ui

## Features

- Add and delete movies
- Mark watched / unwatched
- Star ratings (1–5)
- Filter by genre and status
- Stats: average rating, favorite genre

## Testing

10 JUnit 5 tests, all passing.

## Setup

1. Import the `Sol/MovieWatchlist` folder into Eclipse or IntelliJ
2. Run `WatchlistUI.java` from `src/movie/ui/`

## Project Structure

- `Sol/MovieWatchlist/src/movie/model/` — Movie model
- `Sol/MovieWatchlist/src/movie/service/` — Watchlist business logic
- `Sol/MovieWatchlist/src/movie/ui/` — Swing UI
- `Sol/MovieWatchlist/src/movie/test/` — JUnit tests
- `Doc/` — project documentation
- `ScreenShots/` — app screenshots
